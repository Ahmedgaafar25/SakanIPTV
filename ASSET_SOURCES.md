# Application assets

- The interface uses text, solid colors, CSS gradients and small SVG navigation icons. No promotional artwork, channel-logo requests or poster images are used.
- `app/src/main/assets/cairo.ttf`: Cairo variable font from https://github.com/google/fonts/tree/main/ofl/cairo ; license preserved as `Cairo-OFL.txt`.
- Apache license notices are retained for AndroidX/Media3. Launcher icon and Android TV banner remain required application identity resources.
